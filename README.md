# Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow, from loading and preparing raw data to generating insights and presenting them through interactive dashboards and reports.

The project includes:

* Loading and analyzing data using Python
* Performing Exploratory Data Analysis (EDA)
* Cleaning and transforming the dataset
* Running SQL queries using PostgreSQL
* Building an interactive Power BI dashboard
* Creating an analytical report
* Developing a presentation using Gamma

The goal of this project is to demonstrate practical skills across the complete data analytics lifecycle.

## Project Steps

### 1. Data Loading

The dataset was loaded into Python for initial analysis and processing.

### 2. Exploratory Data Analysis (EDA)

EDA was performed to understand the dataset and identify:

* Data types and structure
* Missing values
* Duplicate records
* Data distributions
* Trends and patterns
* Relationships between variables
* Potential data quality issues

### 3. Data Cleaning

The dataset was cleaned and prepared for analysis by:

* Handling missing values
* Removing duplicates
* Correcting data types
* Standardizing column values
* Identifying and treating invalid or inconsistent data

### 4. SQL Analysis

The cleaned dataset was loaded into a PostgreSQL database.

SQL queries were used to:

* Retrieve and filter data
* Perform aggregations
* Analyze trends
* Compare categories and metrics
* Generate business insights

### 5. Power BI Dashboard

An interactive Power BI dashboard was created to present the key insights visually.

The dashboard includes:

* Key Performance Indicators (KPIs)
* Trend analysis
* Category comparisons
* Interactive filters and slicers
* Business insights based on the data
